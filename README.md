# Сопут — подбор сопутствующих товаров для каталога Комус

Сервис, который к карточке товара komus.ru собирает **расходники, совместимые SKU и позиции «с этим покупают»**, а не похожие товары из той же полки. Степлер ведёт на скобы, лазерный принтер — на картридж и бумагу A4, огнетушитель — на подставку и знак.

Каталог — **все товарные URL из sitemap komus.ru** (~170 тыс. карточек) плюс размеченный срез для отладки рекомендаций. Живой partner API Комус недоступен (антибот), цены и остатки на sitemap нет — карточка Комус открывается по прямой ссылке `/p/{id}/`.

## Что внутри

- **Витрина** `/` и `/p/{артикул}` — поиск и пагинация по полному каталогу, блоки «Расходные материалы», «Подходит к технике», «С этим покупают».
- **Верстак** `/workbench` — мерчандайзер ищет любой артикул Комус, закрепляет или скрывает позиции.
- **Правила** `/rules` — связки категория → категория.
- **Покрытие** `/coverage` — качество выдачи по размеченному срезу.
- **Корзина** `/cart` — сопутка ко всему набору, без дублей уже лежащих SKU.
- **API** `/docs` — контракт для виджета на komus.ru.

### Как ранжируется выдача

1. Закрепление мерчандайзера  
2. SKU-совместимость (картридж к модели, скобы к номеру степлера, чернила EcoTank)  
3. Правило категорий и ключевые слова из названия  
4. Совместные покупки (lift по синтетическим заказам)  
5. Совпадение атрибутов (A4, OEM, ширина скотча) и наличие  

Подмены из той же категории специально опускаются: второй степлер — это не сопутствующий товар.

## Запуск

```bash
npm install
npm test
npm run dev
```

Откройте [http://127.0.0.1:43127](http://127.0.0.1:43127). Сборка: `npm run build && npm start`.

## База товаров для других агентов

Поиск агента по репозиторию часто **не видит** `*.gz`. Каталог уже в git: [`data/komus-catalog.json.gz`](data/komus-catalog.json.gz). Куда смотреть — [`data/HANDOFF.md`](data/HANDOFF.md), контракт — [`data/README.md`](data/README.md).

```bash
python3 scripts/query-komus-catalog.py --stats
python3 scripts/query-komus-catalog.py --id 1042218
python3 scripts/query-komus-catalog.py -q 'степлер' --limit 5
```

С другого воркспейса, без git:

```bash
curl -fsSL http://84.201.169.67/dumps/catalog-locator.json
curl -fsSL -o komus-catalog.json.gz http://84.201.169.67/dumps/komus-catalog.json.gz
```

Пересборка из скачанных sitemap:

```bash
# файлы /tmp/komus-sitemaps/{0..32}.xml
npm run catalog:build
npm run coverage:build
```

Проверка виджета:

```bash
curl -s http://127.0.0.1:43127/api/products/148201/related
curl -s 'http://127.0.0.1:43127/api/products?q=степлер&limit=5'
```

Пример: у `148201` (HP LaserJet 107a) в расходниках будут `148202` / `148203` (картриджи 107A) и бумага A4. Живой артикул `1042218` открывает [карточку на komus.ru](https://www.komus.ru/p/1042218/).

## Встроить на карточку Комус

```
GET /api/products/{id}/related?limit=8&context=pdp
GET /api/products?q=&department=&offset=0&limit=48
POST /api/cart/related
Content-Type: application/json
{ "ids": ["148201", "110101"] }
```

Артикулы из sitemap совпадают с `https://www.komus.ru/p/{id}/`. Размеченные демо-id без записи в sitemap открывают поиск на витрине. Ручные закрепления пишутся в `data/overrides.json`.
