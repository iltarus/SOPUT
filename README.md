# Сопут — подбор сопутствующих товаров для каталога Комус

Сервис, который к карточке товара komus.ru собирает **расходники, совместимые SKU и позиции «с этим покупают»**, а не похожие товары из той же полки. Степлер ведёт на скобы №10, лазерный принтер — на картридж 107A и бумагу A4, огнетушитель — на подставку и знак.

Демо-срез каталога повторяет отделы Комус: канцтовары, бумага, оргтехника, упаковка, хозтовары, спецодежда, кофе, пожарка. Живой API Комус здесь не дергается — антибот закрывает витрину, поэтому стоит размеченный срез и модель совместных покупок.

## Что внутри

- **Витрина** `/p/{артикул}` — карточка как на сайте, блоки «Расходные материалы», «Подходит к технике», «С этим покупают».
- **Верстак** `/workbench` — мерчандайзер закрепляет или скрывает позиции, выдача на карточке обновляется сразу.
- **Правила** `/rules` — связки категория → категория.
- **Покрытие** `/coverage` — где рекомендаций мало.
- **Корзина** `/cart` — сопутка ко всему набору, без дублей уже лежащих SKU.
- **API** `/docs` — контракт для виджета на komus.ru.

### Как ранжируется выдача

1. Закрепление мерчандайзера  
2. SKU-совместимость (картридж к модели, скобы к номеру степлера, чернила EcoTank)  
3. Правило категорий  
4. Совместные покупки (lift по синтетическим заказам)  
5. Совпадение атрибутов (A4, OEM, ширина скотча) и наличие  

Подмены из той же категории специально опускаются: второй степлер — это не сопутствующий товар.

## Запуск

```bash
npm install
npm test
npm run dev
```

Откройте [http://127.0.0.1:43127](http://127.0.0.1:43127). Сборка: `npm run build && npm start`.

Проверка виджета:

```bash
curl -s http://127.0.0.1:43127/api/products/148201/related
```

Пример ответа: у `148201` (HP LaserJet 107a) в расходниках будут `148202` / `148203` (картриджи 107A) и бумага A4.

## Встроить на карточку Комус

```
GET /api/products/{id}/related?limit=8&context=pdp
POST /api/cart/related
Content-Type: application/json
{ "ids": ["148201", "110101"] }
```

Артикул в демо — внутренний id сервиса. Ссылка «Карточка на komus.ru» открывает поиск на витрине: `https://www.komus.ru/search?text=...`. Ручные закрепления пишутся в `data/overrides.json`.
